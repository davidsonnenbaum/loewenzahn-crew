# Captain Dave & die Löwenzahn-Crew

Wir bringen das Land in die Stadt.

Die Website besteht aus reinem HTML, CSS und JavaScript, ohne Baukasten und ohne Build-Schritt. Sie läuft direkt auf GitHub Pages.

## Dateien

- `index.html`: Startseite mit der interaktiven Traum-Szene
- `anheuern.html`: Angebote und Anheuer-Formular
- `app.js`: Animation, Regler und Formular
- `favicon.svg`: das Löwenzahn-Steuerrad

## Vor dem Veröffentlichen ausfüllen

- In `app.js` ganz oben die E-Mail-Adresse bei `CONTACT_EMAIL` eintragen
- Alle Platzhalter in eckigen Klammern, zum Beispiel `[E-MAIL]`, `[INSTAGRAM]`, `[Betrag]`
- Impressum (in Österreich Pflicht)
